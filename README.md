Ответы на контрольные вопросы

1. Что такое IL и зачем он нужен между C# и машинным кодом? 

IL это промежуточный в который компилируется программа на c#. IL нужен для того чтобы jit мог перевести IL в машинный код который понимает процессор

2. Почему .dll можно декомпилировать? 

Потому что .dll содержит IL-код и метаданный а не только готовый машинный код. Из-за этого спец программы например ILSpy могут восстановить из IL структуру исходной программы

3. Какие отличия Debug и Release вы увидели в IL? 

В моей работе в debug было 10 IL-инструкций, а в release 4. D debug есть доп инструкции nop, .locals init (), br.s. В release этого нет поэтому его код метода стал короче

4. Почему Release обычно быстрее Debug?

Потому что при создании release выполняется больше оптимизации. Компилятор старается сделать код более эффективным и убрать ненужные операции

5. Почему строковый пароль в .dll нельзя считать защищённым?

Потому что строковые данные могут находится внутри сборки и быть найденым при анализе .dll. Если записать пароль прямо в коде человек с доступом к файлу может использовать декомпилятор или посмотреть содержимое сборки
